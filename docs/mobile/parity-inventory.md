# React Native parity inventory

This inventory compares the web/mobile behavior at baseline commit `c11f6500cb0b79d652d0164dc06c5fd81624bf0f` with the React Native app in `apps/mobile/`. It records source implementation separately from native device acceptance: a screen or API in the repository does not prove that the full flow works on iOS or Android.

Status labels:

- **Implemented (source):** a React Native screen or native API path exists in this branch.
- **Partial:** some baseline behavior is available, with the listed capability gap.
- **Unverified (device):** no complete iOS and Android device flow has been recorded for this branch.
- **Baseline unresolved:** the original feature claim has not been verified against the baseline implementation.

## Release status

The source has moved beyond a shell-only foundation, but the parity gate remains open. The rows marked partial or with explicit behavior gaps require product implementation or a documented baseline reconciliation. The rows marked unverified need evidence from complete iOS and Android flows.

The mobile CI workflow typechecks the workspace, runs mobile/API unit tests, and exports both native JavaScript bundles. It does not create signed store artifacts, upload builds, or submit the app. See [`artifact-release.md`](./artifact-release.md) for the remaining store gates.
